# 🌸 Popup Image Project

An interactive Popup Image project built using **HTML, CSS, and JavaScript**. 🎀 It uses DOM Manipulation and Event Handling to display images in a popup with a simple and user-friendly interface. ✨

## 💖 Features

- 🖼️ Display images in a popup
- 🖱️ Interactive click events
- ✨ DOM manipulation using JavaScript
- ❌ Close popup functionality
- 🎨 Simple and attractive UI

## 🛠️ Tech Stack

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd YOUR_PROJECT_NAME
```

**3. Run the project**

Open `index.html` in your browser.
